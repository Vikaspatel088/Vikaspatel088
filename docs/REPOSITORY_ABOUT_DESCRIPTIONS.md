## Applying descriptions

1. Confirm the exact repository name and its current purpose.
2. Paste the matching description into GitHub **About → Description**.
3. Add relevant topics only when the repository genuinely uses those technologies.
4. Verify the saved metadata on the repository page and on the profile's pinned card.
5. Do not describe demos, prototypes, or incomplete features as production-ready.

This catalog intentionally includes only repositories whose purpose is sufficiently established. Add remaining repositories after inspecting their README and implementation; do not infer descriptions from repository names alone.
